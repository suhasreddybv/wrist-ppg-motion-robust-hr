# Data: PPG-DaLiA

Wrist PPG (Empatica E4, 64 Hz) with 3-axis accelerometer and chest-ECG reference heart rate, 15 subjects, daily-life activity protocol.

- Source: UCI Machine Learning Repository, "PPG-DaLiA" (Reiss et al., 2019). Check the dataset's current licence terms on the UCI page before publishing any derived files.
- Download and extract so the per-subject pickles sit at `data/PPG_FieldStudy/S1/S1.pkl` … `S15/S15.pkl`.
- `data/` is gitignored except this file. Do not commit raw or derived subject-level data.
